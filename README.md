## v2HDM-to-vSMEFT
---
[![arXiv](https://img.shields.io/badge/arXiv-2611.xxxxx-00aa00.svg)](https://arxiv.org/abs/2611.xxxxx)

This repository contains the ancillary files for 2611.xxxxx about matching v2HDM onto vSMEFT up to one-loop level via functional technique, by Wen-Feng Duan, Xuan-Zhen He, Xin-Qiang Li, Ya-Dong Yang, and Xing-Bo Yuan. Specifically, this repository includes
- one-loop matching between v2HDM and vSMEFT by hand in the folder [@Archive](@Archive/)
- one-loop matching between v2HDM and vSMEFT via [Matchete](https://matchete.gitlab.io) in the folder [@Matchete](@Matchete/)
- one-loop matching between v2HDM and vSMEFT via [Matchmakereft](https://ftae.ugr.es/matchmakereft/) in the folder [@Matchmakereft](@Matchmakereft/)
- [Check.nb](Check.nb) provides the cross-checks among different consequences of separated tools

The matching is performed under NDR and modified MS schemes up to dimension six. The overall Wilson results are provided in [@Archive/wilson.wl](@Archive/wilson.wl) at the heavy scale.

If you use these files, please cite 2611.xxxxx, [2212.04510](https://arxiv.org/abs/2212.04510), and [2112.10787](https://arxiv.org/abs/2112.10787). And if you have any issues, please contact dufewe@mails.ccnu.edu.cn or xqli@mail.ccnu.edu.cn.

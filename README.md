### v2HDM-to-vSMEFT
---
[![arXiv](https://img.shields.io/badge/arXiv-...-00aa00.svg)](https://arxiv.org/abs/...)

This repository contains the ancillary files for the [arXiv number] about matching v2HDM onto vSMEFT at one-loop level via functional technique, by [authors]. Specifically, this repository includes
- one-loop matching between v2HDM and vSMEFT by hand in the folder `@Archive`
- one-loop matching between v2HDM and vSMEFT via [Matchete](https://matchete.gitlab.io) in the folder `@Matchete`
- one-loop matching between v2HDM and vSMEFT via [Matchmakereft](https://ftae.ugr.es/matchmakereft/) in the folder `@Matchmakereft`
- [Check.nb](Check.nb) provides the cross-checks among different consequences of separated tools

The matching is performed under NDR and modified MS schemes up to dimension six. The overall Wilson results are provided in [@Archive/wilson.wl](@Archive/wilson.wl) at the heavy scale.

### Overview
This folder contains the v2HDM-to-vSMEFT matching results using the functional technique via [Matchete](https://matchete.gitlab.io) at the one-loop level, with the following meta-files:
- [vSM.m](vSM.m), [v2HDM.m](v2HDM.m), [vSMEFT-D6.m](vSMEFT-D6.m): Matchete model files to define UV and/or EFT models
- [main.nb](main.nb): Mathematica Notebook to generate the one-loop matching results

### Workflow
1. run [main.nb](main.nb) on Mathematica interface to obtain the one-loop matching results

### Results
The overall results are shown in [OneLoop@Warsaw.wl](OneLoop@Warsaw.wl).
